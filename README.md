Welcome to the Library Management System! This is a simple and user-friendly Python project created to manage daily library operations smoothly through a console menu.

---

## 📌 Features

- **Library Info:** Check library address, name, and timing.
- **Book Operations:** 
  - Add new books to the catalog.
  - Search books by title, author, or category.
  - Display all books and check availability.
  - Remove books when needed.
- **Member Management:**
  - Register new members.
  - Display member lists and search by name/phone.
  - Update contact numbers.
- **Issue & Return:**
  - Issue books to members (maximum 3 books per member).
  - Return issued books and update status automatically.
- **Reports & Statistics:**
  - View overall library stats (Total, Issued, Available percentage).
  - Check transaction history and category-wise reports.
